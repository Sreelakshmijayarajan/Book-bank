# Book Bank - Library Management System

React + Vite frontend-only college project.

## Login
The first page separates **Librarian/Admin** and **Student/Member**.
Any email/password works for this demo.

## After login
### Librarian — exactly 5 main pages
1. Dashboard
2. Books
3. Members
4. Issue Book
5. Loans / Returns

### Student / Member — exactly 5 main pages
1. Dashboard
2. Browse Books
3. My Books
4. Reservations
5. Profile

## Run in VS Code
1. Extract the ZIP.
2. Open the folder in VS Code.
3. Open Terminal.
4. Run `npm install`
5. Run `npm run dev`
6. Open the localhost URL shown by Vite (normally http://localhost:5173).

No backend/database is required for this version. React state is used for the demo, so changes reset on refresh.
